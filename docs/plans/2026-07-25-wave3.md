### Task A3: Options layer — chain ingestion + book Greeks endpoints
**Owns:** `src/quantmind/broker/ib_options.py` (new), `src/quantmind/sources/options_sync.py` (new), `src/quantmind/datastore/store.py` — NO (A2 owns store) → options snapshots stored via existing `write_series`/new parquet under `options/` written through a small `OptionsStore` class in `src/quantmind/datastore/options_store.py` (new, owned), `src/quantmind/api/routers/options.py` (new, pre-registered), `src/quantmind/exposure/book_greeks.py` (new), matching tests (fakes for IB paths; pure math golden-tested).
- Chain ingestion (paced): for configured underliers (SPY, QQQ default): reqSecDefOptParams → select monthlies ≤ 90d, strikes within ±15% of spot → snapshot bid/ask/IV/delta via reqMktData (OPRA entitled) → OptionsStore parquet with as-of. CLI: `python -m quantmind.options_sync_cli` (owned) + wired into /api/sync job optionally (flag).
- `GET /api/options/{underlier}/chain`: cached chain with IV smile per expiry (never-500, staleness stamped).
- `book_greeks.py`: pure — given book positions incl. option legs + chain/IV data → per-underlying net delta/gamma/vega/theta, dollar-delta, SPY-equivalent notional (via per-underlier beta), and stress_grid reuse for the book's option sleeve. Golden tests with hand-computed 2-leg cases (pattern: tests/test_options_risk.py).
- `POST /api/options/book-greeks` accepting book_ref/positions (A1's contract — coordinate via the shared `PositionIn`; extend with optional option-leg fields: strike, expiry, right, multiplier defaulting 100).
