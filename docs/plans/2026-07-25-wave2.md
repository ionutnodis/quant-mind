## Task 3: Hedge Lab page + POST /api/hedge
**Owns:** `src/quantmind/api/routers/hedge.py`, `tests/test_api_hedge.py`, `web/src/pages/Hedge.tsx`, `web/src/test/hedge.test.tsx`.
- `POST /api/hedge`: body `{book: [{symbol, qty}] (1..50), objective: {kind: "beta_target", value: -2.0..2.0}, candidates?: [symbols] default = the cached universe minus book symbols, years 1..25 = 5}`. Compute: book weights/returns/beta vs benchmark (reuse core; same alignment approach as whatif). For each candidate: hedge_qty/notional to move book beta to target (short candidate: size = (beta_book − target) × book_value / (beta_cand × price_cand); flag if candidate beta < 0.1 in absolute value as unusable), hedged portfolio returns = book + hedge position → `es_before`, `es_after` (protection = es_before − es_after), residual beta (recompute), corr_stability = std of 60d rolling correlation book↔candidate (lower = stabler), coint_pvalue (engle_granger book-value-series vs candidate prices — DIAGNOSTIC column only, ranking is by protection per Engineering Constraint 12). Rank by protection desc. ≤20 candidates returned. 422s: unknown symbols, empty usable candidates, bounds.
- Tests: single-candidate hand-checkable case (book = SPY, candidate = QQQ: hedge sizing formula verified arithmetically), ranking order = protection desc, unusable-candidate flag, unknown symbol 422, bounds.
- Page: Objective panel (kind picker [beta_target only, more later], target input), Book builder (same row pattern as What-If), Run button, Ranked candidates table: #, instrument, size (qty + notional), protection (ES before→after, amber), residual β, corr stability, coint p (labeled "diagnostic"); row hover states; honest empty/awaiting. MSW tests: run → ranked table renders with amber protection column; 422 surfaces.
