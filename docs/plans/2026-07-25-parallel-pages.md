## Task 1: Portfolio page + /api/portfolio
**Owns:** `src/quantmind/api/routers/portfolio.py`, `tests/test_api_portfolio.py`, `web/src/pages/Portfolio.tsx`, `web/src/test/portfolio.test.tsx`.
- `GET /api/portfolio`: returns `{snapshot_id, valuation_ts, base_currency, positions: [{con_id, symbol, qty, sec_type, multiplier, last_close|null, market_value|null, weight|null}], totals: {market_value|null, n_positions}}`. Build a `BookSnapshot` (`quantmind.core.snapshot`) for snapshot_id/valuation_ts (valuation_ts = now UTC ISO Z; base_currency "USD").
- Tests: empty (no broker) → 200 structured empty; fake broker with 2 positions (one STK, one OPT multiplier 100) + store fixtures → correct market values/weights; position with no cached bars → null fields, 200.
- Page: dense positions table (Panel chrome; columns Symbol/Type/Qty/Last/Mkt value/Weight, `num` class, right-aligned numerics), totals row, snapshot id + valuation ts in panel note, honest empty state matching Today's language ("No positions in the paper book yet…"). MSW tests: renders rows from mocked API; empty state; weight formatting.

## Task 3: Lab bench (the centerpiece) + apply-to-book endpoint
**Owns:** `src/quantmind/api/routers/lab.py`, `tests/test_api_lab.py`, `web/src/pages/Lab.tsx`, `web/src/test/lab.test.tsx`, `web/src/components/LabFanChart.tsx`.
- `POST /api/lab/apply {model_name, fit: FitResponse-shape, horizon≤2520, n_paths≤200_000, seed?, x0?, exposure: {factor_kind, units, value}}`: simulate via registry model, then `quantmind.exposure.bridge.apply_to_book` (initial = x0 or fit mu) → P&L distribution: histogram bins, mean, p5/p50/p95, ES (mean of worst 2.5%). `UnsupportedMappingError` → 422 with the message. Reuse existing `/api/models/{name}/fit` + `/simulate` — do NOT duplicate them.
- Tests: apply with rate_level/usd_per_bp on an OU fit of fixture data → finite sane numbers; mismatched exposure kind → 422 with "refusing" message; bounds.
- Page — the approved three-zone bench (this is the screen the user approved in mockups): LEFT Panel "Model": model picker from `GET /api/models` rendered generically from schema, data source picker (symbol + years), Fit button → parameter estimates WITH confidence intervals (θ/μ/σ in mono with ± CIs), diagnostics block (ADF p, AIC, log-lik, R²). CENTER Panel "Simulate": LabFanChart — percentile bands (steel, opacity ramp, p50 solid) from `/simulate` `bands` + a few sample paths faint; horizon/paths controls. RIGHT Panel "Apply to Book" — THE amber zone: exposure inputs (factor kind fixed by model schema; units select; value input, e.g. -610 usd_per_bp), Apply button → P&L histogram in amber, ES/percentiles in amber `num`.
