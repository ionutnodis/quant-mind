# Product direction

[← Back to the README](../README.md) · [Current user guide](USER_GUIDE.md) · [Design system](../DESIGN.md)

These are **approved future-state design mockups, not current product screenshots**. They document the intended reconciliation, portfolio-risk, and decision-review experience. Names, positions, and values are illustrative, never broker data.

For what works today, see the [user guide](USER_GUIDE.md). In particular, the current Risk page analyses one symbol; the book-level factor X-ray shown below is not implemented yet.

## Reconcile before publishing a book

Make source-to-canonical position reconciliation and missing evidence visible before a book can be used for analysis.

## Explain concentration as risk, not only capital weight

Compare capital allocation with named sources of portfolio risk, while keeping the underlying evidence inspectable.

Keep before-and-after decisions tied to immutable book and evidence references.
